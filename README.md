# 📝 Interactive To-Do List

Uma aplicação web interativa para gerenciamento de tarefas do dia a dia, focada em usabilidade, produtividade e manipulação dinâmica do DOM utilizando **JavaScript vanila**, **HTML5** e **CSS3**.

---

## 🚀 Funcionalidades e Recursos

- ➕ **Gerenciamento Completo de Tarefas:** Adição, edição em tempo real e remoção/exclusão de itens da lista.
- ✔️ **Marcação de Conclusão:** Ao marcar uma tarefa como concluída:
  - Aplica estilo visual destacado (fundo escurecido, texto tachado e itálico).
  - Move automaticamente a tarefa concluída para o final da lista.
- 🔍 **Busca & Filtros Dinâmicos:**
  - Barra de pesquisa para filtrar tarefas por palavra-chave em tempo real.
  - Filtros por status: **Todas**, **Pendentes** e **Concluídas (Feitos)**.
- 🖐️ **Drag & Drop (Arrastar e Soltar):** Reordenação intuitiva das tarefas arrastando os itens para cima ou para baixo com o mouse.
- 🎨 **Interface Limpa e Intuitiva:** Design moderno com bom contraste e usabilidade fluida.

---

## 🛠️ Tecnologias Utilizadas

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estrutura semântica para os formulários, campos de busca, filtros e lista de itens.
- **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Estilização modular, animações suaves, estados visuais de conclusão e regras de ordenação.
- **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):** Manipulação do DOM, eventos de teclado e mouse, implementação da API de Drag & Drop e lógica de ordenação e filtragem de dados.
- **[Git & GitHub](https://github.com/):** Controle de versão do código.

## 🔧 Como Executar o Projeto Localmente

1. **Clone o repositório:**

2. **Acesse a pasta do projeto:**

3. **Abra no navegador:**
